# Frontend Foundation

A reusable client website foundation powered by React + Vite + TanStack Router. Business features are intentionally **not** implemented yet — the client is not determined, so all content is placeholder.

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Router (file-based routing)
- TanStack Query
- Tailwind CSS v4
- oxlint

## Development

```bash
npm install
npm run dev
```

Frontend dev server runs at `http://localhost:5173`.

## Scripts

| Command           | Description                   |
| ----------------- | ----------------------------- |
| `npm run dev`     | Start Vite dev server         |
| `npm run build`   | Type-check + production build |
| `npm run preview` | Preview production build      |
| `npm run lint`    | Run oxlint                    |

## Environment

Copy `.env.example` to `.env` and adjust if needed:

```bash
VITE_API_URL=http://127.0.0.1:8080
```

`.env` is gitignored. `.env.example` is committed.

Only `VITE_*` variables are exposed to the browser. Never put backend secrets here.

## Backend

The Go backend runs on `http://127.0.0.1:8080`:

- `GET /health` — used by the dev-only Backend Status card on the home page to verify the chain `React → TanStack Query → API client (fetch) → Go backend`.
- `POST /api/v1/ai/chat` — exposed as `aiApi.chat()` in `src/lib/api/ai.ts` for future use.

## Routing

Placeholder routes currently available:

- `/` — home page demonstrating the layout and component system
- `/about` — placeholder
- `/contact` — placeholder
- anything else renders the 404 page

## Structure

```
src/
├── App.tsx                    # Providers + Router
├── main.tsx                   # Entry point, theme init
├── components/
│   ├── dev/                   # Dev-only utilities (HealthStatus)
│   ├── feedback/              # LoadingState, ErrorState, EmptyState
│   ├── layout/                # RootLayout, Footer
│   ├── navigation/            # Navbar (responsive, active state, theme toggle)
│   ├── sections/              # Section, SectionHeader, Hero, FeatureGrid, CardGrid, CTA
│   └── ui/                    # Reusable primitives (Button, Card, Input, Modal, ...)
├── config/
│   └── site.ts                # Central placeholder site config (brand, nav, contact)
├── hooks/                     # useTheme, useMediaQuery, useDisclosure
├── lib/
│   ├── api/                   # client.ts (fetch abstraction), health.ts, ai.ts
│   ├── query-client.ts
│   └── utils/cn.ts
├── providers/                 # ThemeProvider (dark-first, light support)
├── routes/                    # File-based routes (__root, index, $, about, contact)
├── styles/index.css           # Tailwind v4 theme, tokens, dark mode
├── types/                     # api.ts, env.d.ts
└── routeTree.gen.ts           # Auto-generated by TanStack Router
```

## Theme

Dark mode first. The `ThemeProvider` toggles a `dark` class on `<html>` and persists the choice in `localStorage`. Design tokens (colors, radius, animations) are defined in `src/styles/index.css` — swap the CSS variables there when the client brand is known.

## Conventions

- Mobile-first responsive design
- Semantic HTML, focus-visible styles, reduced-motion support
- No business-specific content anywhere — replace placeholder copy via `src/config/site.ts` and route pages when requirements arrive
