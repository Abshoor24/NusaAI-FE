# Frontend

Frontend foundation powered by React + Vite + TanStack Router. Business features are intentionally **not** implemented yet, since the client is not determined.

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Router (file-based routing)
- TanStack Query
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Frontend dev server runs at:

```
http://localhost:5173
```

Routes available as placeholders:

- `/`
- `/about`
- `/contact`
- anything else renders the 404 page

## Scripts

| Command            | Description                        |
| ------------------ | ---------------------------------- |
| `npm run dev`      | Start Vite dev server              |
| `npm run build`    | Type-check + production build      |
| `npm run preview`  | Preview production build           |
| `npm run lint`     | Run oxlint                         |

## Environment

Copy `.env.example` to `.env` and adjust if needed:

```bash
VITE_API_URL=http://127.0.0.1:8080
```

`.env` is gitignored. `.env.example` is committed.

Only `VITE_*` variables are exposed to the browser. Never put backend secrets here — everything is public.

## Backend

The Go backend (see [Abshoor24/backend-go](https://github.com/Abshoor24/backend-go)) runs on:

```
http://127.0.0.1:8080
```

Health endpoint:

```
GET /health
```

The home page includes a dev-only "Backend Status" card that queries `/health` and shows `Connected` / `Disconnected`. It verifies the chain:

```
React → TanStack Query → API client (fetch) → Go backend :8080
```

## Structure

```
src/
├── components/
│   └── layout/        # Navbar, Footer, MainLayout
├── features/
│   └── health/        # health.api.ts, health.types.ts, HealthStatus.tsx
├── lib/
│   ├── api.ts         # native fetch API client (GET, POST)
│   └── query-client.ts
├── routes/            # file-based routes (__root, index, about, contact, $)
├── types/
│   └── api.ts         # generic ApiResponse<T>
├── main.tsx
└── routeTree.gen.ts   # auto-generated by TanStack Router plugin
```
